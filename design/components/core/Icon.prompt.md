Every icon in the client comes from Material Design icons. Use ligature names: `settings`, `refresh`, `close`, `arrow_back`, `mic`, `mic_off`, `volume_up`, `volume_off`, `wifi_off`, `link_off`, `error`, `arrow_drop_down`.

```jsx
<Icon name="mic_off" size={20} color="#fff" />
```

Default colour is `--text-icon` (#777), which is what every title-bar icon uses.
