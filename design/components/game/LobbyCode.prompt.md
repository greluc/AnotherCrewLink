The only monospace text in the product. It exists because people read it aloud and type it in, so it is large, spaced, and never in the UI font.

```jsx
<LobbyCode code="XKJDPQ" background="var(--crew-cyan)" />
```

A code is a credential: honour `hidden` whenever the design might be on a stream.


Tint with the player's crew colour, but take the pair's **shadow** half for the bright colours (cyan, lime, yellow, white) — white text on `#38FEDC` burns out.

**Rust counterpart:** `views/main.rs`, which draws it above the roster.
