# 11 — Audit of the code the first audit never opened, 2026-08-29

The first audit ([10](10-audit-2026-08-29.md)) ended with a list of what nobody had looked
at: the whole of `acl-game`, `acl-ipc` and `acl-helper`, `acl-core`'s platform layer, the
effects half of the mix graph, and the interface. This is that list, audited the same way —
eight parallel finders, every finding handed to a sceptic told to refute it, a completeness
critic at the end.

**Thirty-three findings survived. Seven were refuted.** Three more came from the critic.

The first audit found a client whose *network* did not repair itself. This one found a
client whose *game reader* does not either, and the two failures rhyme: a thing that can
only go wrong once, and no code path that notices it has.

---

## A. The game goes away and never comes back

### A1 ⚠ `read_state` cannot fail, so the helper never re-attaches

`crates/acl-game/src/reader.rs:341` · `crates/acl-helper/src/main.rs:445`

`read_state` is declared `-> Result<AmongUsState, ReadError>` and every fallible read
inside it is hedged: `follow(...).unwrap_or(0)`, `read_u32_at(...).unwrap_or(4)`,
`read_i32_at(...).unwrap_or(-1)`. The body ends unconditionally at `Ok(AmongUsState { … })`.
It is infallible for *any* `ProcessMemory`, including one whose every read fails.

So `Sampler::sample` is infallible, so the `else` arm in the helper — whose comment reads
*"The game went away … a player restarting the game should get their proximity back without
restarting the client"* — is **dead code**. `Sampler::attach` is called once per helper
process, and the handle is held for its whole life.

What happens when the game exits is worse than nothing: every read fails to zero,
`gameState` falls back to 4, `lobby_code_int` to −1, the code becomes `""`, and
`lobby_code_for` turns that into `"MENU"`. The helper emits **well-formed menu frames at
5 Hz, for ever.** The client sees a menu, so it leaves the voice room and never rejoins —
nobody hears anybody, the lobby is unpublished, and the title bar says "Menu". Recovery
needs the ⟳ button or a restart.

`GameReader.ts:203` runs `checkProcessOpen()` every thirty iterations and re-attaches within
about six seconds.

### A2 ⚠ The offsets store is unreachable

`crates/acl-client/src/reader.rs:266`

No lookup, no `broadcastVersion` scan, no mirror fetch. The client runs on the compiled-in
floor and nothing else, which means a game update breaks it until a new client ships —
`offsetStore.ts` exists precisely so it does not.

### A3 ⚠ An elevated game reads as "no game", for ever, silently

`crates/acl-core/src/launch.rs:162` · `crates/acl-client/src/reader.rs:245`

`ERROR_ACCESS_DENIED` from `OpenProcess` is not distinguished from "process not found", and
nothing re-launches the helper through UAC. The elevation path exists and has no caller. A
player who runs Among Us as administrator gets no game state, no prompt, and no explanation.

## B. The helper, and the pipe to it

### B1 ⚡ A lost helper is never restarted
`crates/acl-core/src/helper.rs:209` — the restart policy has zero callers, and
`Reader::latest` keeps serving a frozen frame.

### B2 One overlay frame is 1.4× the pipe buffer
`crates/acl-ipc/src/pipe.rs:86` — a full lobby's sprites do not fit, so the write blocks the
only thread that also drains game state.

### B3 The overlay never comes back after the helper is replaced
`crates/acl-client/src/main.rs:1330` — `overlay_shown` latches true and the new helper is
never told to show it.

### B4 (critic) The overlay is topmost and never hidden on focus loss
`crates/acl-client/src/main.rs:1253` — it floats over every other application for the rest
of the round.

### B5 (critic) ⚡ Exclusive-fullscreen detection is never called
`crates/acl-core/src/fullscreen.rs:86` — an overlay that cannot be composited simply never
appears, with nothing to say why.

### B6 (critic) ⚡ The overlay never draws player names
`crates/acl-ui/src/overlay_layout.rs:85` — `Position::shows_names` has no production caller,
so the two "with names" positions are indistinguishable from the plain ones.

## C. Keys

### C1 Binding mute or deafen mutes you on the spot
`crates/acl-client/src/settings_page.rs:283` — a shortcut created while its key is down
records `down: false` and reads the release as a press. 1.x carries a comment about this
exact bug.

### C2 Mute and deafen are polled at 5 Hz
`crates/acl-client/src/main.rs:1569` — an ordinary key tap between two repaints is not seen
at all. The same seam audit 1's E3 and E4 ask for on the audio side.

### C3 A shortcut bound to `NumpadEnter` is dead and nobody is told
`crates/acl-core/src/shortcuts.rs:378` — the module's own doc says the caller tells them.

## D. Audio

### D1 A non-finite hearing range panics the mixer thread
`crates/acl-audio/src/panner.rs:93` — and release builds abort. The coordinate that
produces it is D6.

### D2 The resampler's chunk is 960 frames at every rate
`crates/acl-client/src/audio.rs:782` — so a 16 kHz microphone emits three 20 ms frames in
one burst and only the first gets a far-end reference.

### D3 `microphoneGain` is applied ahead of the voice detector
`crates/acl-client/src/audio.rs:851` — in `Voice.tsx` the analyser is upstream of the gain
node, so turning the gain up here also raises the floor the detector learned.

### D4 The capture callback holds the reference lock across the echo canceller
`crates/acl-client/src/audio.rs:874` — so the output callback's `try_lock` loses and whole
buffers of reference are thrown away.

### D5 The reverb is panned after convolution
`crates/acl-client/src/audio.rs:1327` — the whole three-second tail is re-placed from the
ghost's current position every frame.

### D6 A non-finite coordinate reaches the speaker
`crates/acl-game/src/reader.rs:427` — the Electron reader turns it into 999 and this one
does not.

### D7 A haunting ghost's tail is cut when they walk out of earshot
`crates/acl-audio/src/voice.rs:371` — `Reach::Silent` drops `reverb`, so the guard in
`main.rs` written to keep the tail alive never fires.

### D8 The reverb's normalisation constant is a rounded literal
`crates/acl-audio/src/convolver.rs:26` — 0.00125 where Chromium derives 10^(−58/20), and the
golden gate's absolute threshold cannot see the difference.

### D9 The detector spends a second learning a floor 1.x never learns
`crates/acl-audio/src/vad.rs:21` — `Voice.tsx` does not calibrate at all.

### A2's other half needs a protocol change

The lookup is keyed by the build hash the game broadcasts, and only the helper can read
that — it is in the game's memory. Asking would need a round trip the pipe does not have,
because offsets are sent once, at start, before the helper has attached to anything. So the
client takes the lookup's `default` entry, which is what the mirror says the current build
is: right for the case the store exists for, and no worse than the floor for anybody on an
older game, because the floor is one specific build too. Reading the broadcast hash needs a
`GetBuild` message and a second `SetOffsets`.

### B6 is a feature this port has not built

Drawing names in the overlay needs a font, a glyph rasteriser and a name column in
`overlay_layout`, and `acl_ui::sprite` has none of the three — it draws circles and
composites bitmaps. That is a feature rather than a wiring mistake, and half-building it
would put an untested text path into the one surface nobody here can look at.

What was fixed is the silence: a player who picks one of the two "with names" positions now
gets a line in the log saying the names are not drawn yet, so a setting that does nothing is
at least a setting that says so.

## Refuted — do not raise these again

- `reader.rs:269` `oldGameState` produced and never read. It is read.
- `link.rs:178` nothing bounds a silent helper. There is a deadline and it is applied.
- `link.rs:333` no `log` implementation anywhere. `acl_core::logging` installs one; what
  audit 1 found (C1) is that it is installed *late*, after the transport's warnings.
- `audio.rs:669` the reference divided by an unwritten channel count.
- `net.rs:831` every close reason discarded, including the retirement sentence.
- `session.rs:519` `setHost` read by nothing.
- `server_url.rs:44` `is_valid` has zero callers. It has one.

## Method

Identical to audit 10, on the eight dimensions the first left out: reading the game out of
process memory, the state it publishes, the named pipe and the overlay helper, the platform
layer, the effects half of the mix graph, the newest audio code, the Engine.IO and
Socket.IO wire, and the interface with the updater and the translations. Forty-nine agents.
Verification was capped at the five most severe per dimension; everything dropped is in the
run log rather than silently cut.
